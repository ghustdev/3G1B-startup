The official landing page for **3G1B Startup**, a forward-thinking innovation studio specializing in high-impact digital products. This project showcases our expertise in modern web development, featuring a fully responsive, internationalized, and visually stunning interface.

## 🚀 Features

- **🌐 Internationalization (i18n)**: Seamless English/Portuguese (EN/PT) language toggling using React Context.
- **🎨 Futuristic Design**: "Digital Future" aesthetic with custom grid backgrounds, glassmorphism, and vibrant neon gradients (Cyan/Purple).
- **✨ Advanced Animations**: Powered by **Framer Motion**, featuring:
    - **Interactive Blueprint**: A 3D-tilted, scanning, data-flowing software architecture diagram.
    - **Scroll-triggered reveals**: Elements fade and slide in as you explore.
    - **Parallax effects**: Dynamic depth and movement.
- **📱 Fully Responsive**: Optimized for all devices, from mobile phones to ultrawide monitors.
- **⚡ High Performance**: Built on **Next.js 14 (App Router)** for lightning-fast loading and SEO optimization.
- **🧩 Component-Based**: Modular architecture using **React** and **Shadcn UI**.

## 🛠️ Tech Stack

- **Framework**: [Next.js 14](https://nextjs.org/) (App Router)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **UI Components**: [Shadcn UI](https://ui.shadcn.com/)
- **Icons**: [Lucide React](https://lucide.dev/)

## 📂 Project Structure

```bash
src/
├── app/                # Next.js App Router pages
│   ├── layout.tsx      # Root layout with LanguageProvider
│   ├── page.tsx        # Main landing page
│   └── projects/       # Projects portfolio page
├── components/
│   ├── layout/         # Header, Footer
│   ├── sections/       # Landing page sections (Hero, About, Blueprint, etc.)
│   └── ui/             # Reusable UI components (Buttons, Cards, etc.)
├── contexts/           # React Contexts (LanguageContext)
└── lib/
    ├── i18n.ts         # Translation dictionary
    └── utils.ts        # Helper functions
```
